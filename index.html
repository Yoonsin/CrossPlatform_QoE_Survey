QoE 설문조사

각 항목에 대해 본인의 생각과 가장 가까운 점수를 선택해 주세요.

📋 설문 참여 안내
  1. 참가자 ID를 먼저 입력해 주세요. (예: 김이름)
  2. 아래 세그먼트 추가 버튼을 눌러 평가할 영상 세그먼트를 추가하세요. (최대 6개)
  3. 각 세그먼트마다 시나리오 번호와 단계 (적용 전/후)를 선택해 주세요.
  4. Q1~Q4 각 문항에서 본인의 경험과 가장 가까운 점수 (1~5)를 선택해 주세요.
  5. 자유 의견란은 선택 사항입니다. 느낀 점을 자유롭게 작성하셔도 됩니다.
  6. 모든 세그먼트 응답 완료 후 하단의 제출하기 버튼을 눌러 주세요.
🎮 시나리오 설명
  • 시나리오 1두 플레이어가 같은 위치에 있고, 같은 목표를 사격합니다.
    한 플레이어라도 목표 점수 10점을 채우면 게임이 종료됩니다.
  • 시나리오 2모바일은 왼쪽, PC는 오른쪽에 있으며 각자 다른 목표를 사격합니다.
    두 플레이어 모두 목표 점수 10점을 채우면 게임이 종료됩니다.
  • 시나리오 1,2 모두 두 플레이어는 경쟁이 아니라 협력하는 입장 입니다.
  • 즉, 다른 플레이어가 점수를 얻은 것은 같은 팀(파티)의 득점으로 보아야합니다.
  • 시나리오의 목표는 플레이어 두 명이서 같이 점수를 빨리 채우는 것입니다.
  • 물체 사격 시 이펙트가 발생하며, 모바일은 빨간색, PC는 파란색으로 표시됩니다.
  • (*로컬 플레이어의 사격은 로컬 월드 기준으로, 원격 플레이어의 사격은 서버 월드 기준으로 물체를 맞췄다고 판정됐을 때 발생합니다.)
  • 처음 실험하는 경우, 각 시나리오 플레이 전 튜토리얼을 한 번씩 진행합니다.
  • 화면 위쪽 점수판에서 자신의 점수는 항상 왼쪽에 표시됩니다.
